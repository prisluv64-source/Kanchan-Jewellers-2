# Jewellery Website V1

Static responsive jewellery showroom website prepared for Vercel deployment.

## Run locally
Open `index.html` directly in a browser, or run any static web server from this folder.

## Before publishing
Replace these placeholders in `index.html` and `script.js`:
- Business name (`Your Jewellers`)
- Logo initials (`YJ`)
- WhatsApp/phone number (`919999999999`)
- Shop address and timings
- About text
- Actual product/category photographs
- Google Maps embed

## Vercel
This is a static site. Create a new Vercel project and deploy this folder directly.
